# Foto del carosello "Mentalità"

Trascina qui le tue foto: vengono **caricate automaticamente** nel carosello della
sezione About → card "Mentalità". Non serve modificare il codice.

## Come funziona
- Formati accettati: `.jpg` `.jpeg` `.png` `.webp` `.avif` `.svg`
- L'ordine di rotazione segue il **nome del file** in ordine alfabetico.
  Usa un prefisso numerico per controllarlo: `01-...`, `02-...`, `03-...`
- Il testo mostrato sotto la foto è ricavato dal nome del file:
  `01-passione.jpg` → **PASSIONE** (il prefisso numerico e i trattini vengono rimossi).
  Se non vuoi didascalia, chiama il file solo `01.jpg`, `02.jpg`, ecc.
- Proporzioni consigliate: verticali **3:4** (es. 600×800). Le foto vengono
  ritagliate con `object-cover`, quindi va bene qualsiasi dimensione.
